# Security Policy

CivicSignal handles vote privacy, pseudonymous verification, moderation state, service-role credentials, and future audit commitments. Please report sensitive security issues privately rather than opening a public GitHub issue.

## Please report privately

Use private disclosure for issues involving:

- Authentication or session bypass
- Supabase service-role key exposure
- Vote privacy or sealed-vote leakage
- Identity verification or anti-Sybil bypass
- Reputation tampering
- Audit-log, receipt, or commitment integrity
- Stored XSS, SSRF, SQL injection, or privilege escalation

## Public issues are fine for

- Documentation corrections
- UI bugs without private data exposure
- Poll wording/source-template improvements
- Non-sensitive build or local development problems

## Disclosure expectations

Include a concise description, reproduction steps, affected areas, and impact. Do not include real identity documents, production secrets, or private voter data in reports.
